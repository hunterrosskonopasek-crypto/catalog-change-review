# Check a winter catalogue release

Two 25 kg bags in MacGregor Industrial Supplies’ winter range have different item codes. Its white-salt offer also changes at 49 bags. HWC built this independent exercise from public records. All staged orders below are fictional.

[Download the interactive check](winter-catalog-check.html?raw=1) and open the HTML in a browser. The three fields and comparison work offline. If GitHub displays source code, use **Download raw file**.

| Public item | Product code | Storefront SKU | Pack |
| --- | --- | --- | --- |
| [White de-icing salt](https://mymacgregors.co.uk/product/16478) | DEI0025 | 10029421 | 25 kg bag |
| [Brown rock salt](https://mymacgregors.co.uk/product/16442) | BS0025 | 10029410 | 25 kg bag |

1. Open the example at 49 white bags priced at £5.28 each. The published 49+ tier is £5.00 per bag. The staged total is £258.72 and the reference is £245.00, a £13.72 difference before VAT.
2. Change the price to £5.00. The SKU and price tier now match.
3. Select the brown SKU. Both bags still weigh 25 kg. The checker flags the item mapping before evaluating white-salt pricing.

The public offer gives £6.30 for 1–9 bags, £5.60 for 10–29, £5.28 for 30–48 and £5.00 for 49+. All are per bag, ex VAT. A production check requires the buyer’s approved price list, account terms and release dates. [MacGregor’s volume offer](https://www.macgregorsupplies.co.uk/de-icing-salt-special-offer)
